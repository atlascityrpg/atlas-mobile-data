# 🇵🇹 Português

## Sobre o projeto

Este repositório é dedicado à distribuição dos recursos oficiais e autorizados do **ATLAS MOBILE**, o cliente Android desenvolvido para o servidor **ATLAS CITY RPG**.

O objetivo é disponibilizar atualizações, pacotes de recursos e ficheiros necessários ao funcionamento do launcher, através de um sistema de distribuição organizado e verificável.

A infraestrutura foi pensada para trabalhar em conjunto com o ATLAS MOBILE, incluindo verificação de integridade através de SHA-256.

## 📦 Distribuição

Os ficheiros de distribuição serão disponibilizados através de **GitHub Releases**, evitando adicionar ficheiros de grandes dimensões ao histórico do Git.

Os pacotes poderão incluir:

| Pacote | Descrição |
|---|---|
| ATLAS LITE | Conjunto reduzido de recursos próprios e autorizados |
| ATLAS FULL | Conjunto completo de recursos próprios e autorizados |
| Updates | Atualizações e correções dos recursos distribuídos |

A disponibilidade dos pacotes depende das respetivas publicações nas Releases.

## 🔐 Integridade e segurança

A integridade dos ficheiros é uma prioridade.

O sistema de distribuição foi preparado para utilizar:

- Verificação SHA-256.
- Identificação de versões.
- Verificação de tamanho dos ficheiros.
- Deteção de ficheiros incompletos ou alterados.
- Atualizações diferenciais, quando suportadas.
- Downloads retomáveis, quando suportados pelo servidor.

O objetivo é garantir que os recursos recebidos pelo ATLAS MOBILE correspondem aos ficheiros publicados.

## ⚙️ Compatibilidade

Os recursos destinam-se ao ATLAS MOBILE e às versões de cliente compatíveis.

A compatibilidade de cada pacote será indicada na respetiva publicação.

## ⚠️ Nota sobre os dados do GTA San Andreas

Este repositório não se destina à distribuição não autorizada de ficheiros proprietários da Rockstar Games ou Take-Two Interactive.

Os dados proprietários necessários ao funcionamento do GTA San Andreas deverão ser obtidos legalmente pelo próprio utilizador, através da sua cópia legítima do jogo.

Este repositório disponibiliza apenas recursos próprios do ATLAS e ficheiros cuja distribuição esteja devidamente autorizada.

# 🇬🇧 English

## About the project

This repository is dedicated to distributing official and authorized resources for **ATLAS MOBILE**, the Android client developed for the **ATLAS CITY RPG** server.

Its purpose is to provide updates, resource packages and files required by the launcher through an organized and verifiable distribution system.

The infrastructure is designed to work alongside ATLAS MOBILE, including SHA-256 integrity verification.

## 📦 Distribution

Distribution files will be published through **GitHub Releases**, keeping large files out of the Git repository history.

Packages may include:

| Package | Description |
|---|---|
| ATLAS LITE | A reduced set of original and authorized resources |
| ATLAS FULL | A complete set of original and authorized resources |
| Updates | Updates and fixes for distributed resources |

Package availability depends on the corresponding Release publications.

## 🔐 Integrity and security

File integrity is a priority.

The distribution system is designed to support:

- SHA-256 verification.
- Version identification.
- File size verification.
- Detection of incomplete or modified files.
- Differential updates, where supported.
- Resumable downloads, where supported by the hosting service.

The goal is to ensure that resources received by ATLAS MOBILE match the published files.

## ⚙️ Compatibility

Resources are intended for ATLAS MOBILE and compatible client versions.

Package compatibility information will be provided with each release.

## ⚠️ Regarding Grand Theft Auto: San Andreas game data

This repository is not intended for the unauthorized distribution of proprietary files belonging to Rockstar Games or Take-Two Interactive.

Proprietary game data required to run Grand Theft Auto: San Andreas must be legally obtained by the user through their own legitimate copy of the game.

This repository distributes only original ATLAS resources and files that are properly authorized for distribution.
